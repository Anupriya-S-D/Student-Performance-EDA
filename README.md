# Student Performance EDA

## Aim
To perform Exploratory Data Analysis (EDA) on a student academic performance dataset using statistical measures and data visualization techniques.

## Description
This experiment analyzes student academic performance using Python. The dataset includes study hours, attendance, internal marks, and final scores. Statistical analysis and visualization techniques are used to identify patterns, distributions, outliers, and relationships among the variables.

## Tools Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis Performed
- Dataset inspection
- Missing values and duplicate checking
- Descriptive statistical analysis
- Histogram visualization
- Boxplots and outlier detection
- Scatter plots
- Correlation analysis and heatmap

## Results
The dataset contains 18 students with no missing or duplicate values. The average final score is 62. One outlier was identified with a final score of 22. Attendance and internal marks showed strong positive correlations with final scores.

## Conclusion
EDA helped understand the dataset, identify outliers, visualize score distributions, and analyze relationships between academic variables. The analysis indicates that attendance and study habits are associated with student academic performance.
